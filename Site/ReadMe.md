Описание проекта
Разработанный программный комплекс это гибридная система извлечения именованных сущностей адаптированная специально для научно-технического дискурса. Система принимает на вход неструктурированный текст и извлекает из него объекты принадлежащие к семи целевым классам. К ним относятся математические термины, составные определения, имена ученых, названия теорем, переменные, операторы и математические формулы.

Архитектура конвейера
В основе системы лежит микросервисная архитектура разделяющая вероятностный и детерминированный подходы. Первый аналитический слой работает на базе предобученной языковой модели BERT. Нейронная сеть анализирует широкий лингвистический контекст и формирует вероятностные гипотезы для поиска имен терминов и теорем. Второй слой это независимый модуль парсинга на основе регулярных выражений. Он игнорирует обычный текст и опирается на строгий синтаксис для точного извлечения формул и уравнений.

Разрешение коллизий
Для объединения результатов параллельных вычислений работает арбитражный контроллер. Он накладывает статистическую разметку на жесткие координаты парсера. Если нейросеть находит отдельную буквенную переменную внутри уравнения, арбитр отдает приоритет формальной грамматике и формула поглощает мелкую сущность. Также контроллер способен восстанавливать границы математических выражений если языковая модель случайно оборвала предсказание из-за проблем с токенизацией.

Серверная часть и дообучение
Бэкенд спроектирован на фреймворке FastAPI и работает через асинхронный шлюз. Тяжелые веса трансформера загружаются в оперативную память строго один раз при старте приложения что надежно защищает систему от утечек памяти. Все клиентские запросы обрабатываются параллельно без блокировки основного цикла сервера. В архитектуре также предусмотрен изолированный контур автономного дообучения. Валидированные системой примеры потоково сохраняются в формате JSONL для регулярного обновления весов модели в фоновом режиме.

Описание обучающей выборки
Разработка математического анализатора потребовала создания собственного датасета. Стандартные открытые корпуса текстов оказались полностью лишены математической нотации уравнений и профильных терминов. Обучение на таких данных привело бы к деградации модели поэтому был применен метод процедурной генерации признакового пространства.

Механика генерации
Сборка данных базируется на комбинаторике пулов атомарных сущностей. В оперативной памяти системы хранятся изолированные словари антропонимов, сложных предметных терминов и математических формул различной глубины вложенности. Алгоритм динамически маршрутизирует эти элементы в пустые слоты заранее подготовленных синтаксических шаблонов. Это позволяет генерировать грамматически корректные и семантически уникальные предложения полностью контролируя баланс редких классов в выборке.

Стандарт разметки
Сгенерированный сырой текст автоматически проходит через скрипт позиционной аннотации по индустриальному стандарту BIO. Каждому токену жестко присваивается тег начала целевой сущности, продолжения сущности или фонового шума. Строгая алгоритмическая разметка полностью исключает человеческий фактор, не допускает смещения индексов и гарантирует идеальное определение границ каждого слова. Накопленный таким образом синтетический датасет выступает в роли эталонного массива для формирования устойчивых начальных весов перед запуском нейросети в эксплуатацию.


Шаг 1. Установка зависимостей

Распакуйте архив с проектом в удобную папку.

Откройте терминал в корневой папке проекта где находится файл requirements.txt.

Рекомендуется создать виртуальное окружение, но можно установить библиотеки и глобально. Введите команду:
pip install -r requirements.txt

Дождитесь окончания установки библиотек

Шаг 2. Запуск локального сервера

В той же командной строке перейдите в папку Site. Для этого введите:
cd Site

Запустите сервер веб-приложения командой:
uvicorn app:app

Если всё прошло успешно, в консоли появится сообщение:
Application startup complete и Uvicorn running on http://127.0.0.1:8000.

Шаг 3. Работа с приложением

Откройте любой современный веб-браузер.

Введите в адресную строку:
http://127.0.0.1:8000/

Откроется интерфейс анализатора. Вы можете вставить текст вручную в окно или загрузить готовый .txt файл, после чего нажать «Запустить анализ».

Обработка текста может занять несколько секунд в зависимости от мощности процессора.

Шаг 4. Завершение работы
Чтобы остановить сервер, вернитесь в командную строку и нажмите комбинацию клавиш Ctrl + C.

Примечание: Если порт 8000 уже занят другим приложением на вашем ПК, вы можете запустить сервер на другом порту командой: uvicorn app:app --port 8080 и перейти по адресу http://127.0.0.1:8080/.



как работают программы:
   
Обучающая выборка базируется на реальных научно-технических текстах с математической нотацией. Исходный датасет был предоставлен сторонним исследователем и содержит фрагменты настоящих научных статей. Все собранные данные прошли предварительную очистку от артефактов верстки и были строго размечены по стандарту BIO для выделения семи целевых классов сущностей. Использование массива реального текстового материала вместо искусственных шаблонов позволило языковой модели выучить естественный контекст математических формул и профильных терминов без риска искажений.

Обучение модели (Google Colab или файл train.py): Затем в облачной среде Google Colab поочередно запускаются ячейки кода (ноутбук .ipynb), которые загружают подготовленный датасет и тренируют на нем базовую нейросеть BERT, после чего готовые веса обученной модели скачиваются на локальный компьютер в папку saved_model.

Запуск сервера (app.py): Далее на компьютере в командной строке командой uvicorn app:app запускается серверный скрипт, который подгружает скачанную модель в память, принимает новые тексты, применяет алгоритмы склейки разорванных слов, отсеивает мусор и классифицирует термины.

Интерфейс пользователя (index.html): В самом конце в браузере открывается адрес http://127.0.0.1:8000/, где работает визуальная форма: она принимает текст от пользователя, передает его на запущенный сервер и выводит готовый результат в виде подсвеченного текста и цветных блоков категорий.
