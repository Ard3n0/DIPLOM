# Извлечение и классификация сущностей в научных текстах по математике

Алгоритм автоматической разметки сущносей из научных текстов. Предназначен для получения ключевых терминов из входного текста. Работает в локальной сети.

# Сущности

Var - переменные
Operator - математические функции
Formula - формулы
Name - ФИО учёных в тексте
Term - математические термины
Theorem - теоремы

# Архитектура

Двухпоточная работа - при разметке взаймодействуют 2 потока - регулярные выражения для формул и модель на основе RuBERT-tiny2 для поиска всех сущностей

Арбитражный контроль - разрешение конфликтов при совпадении координат у двух потоков

Непрерывное обучение - в случае уверенности в обнаружении сущности более чем на 50% - данная разметка идет в накопительный буфер. при достижении 200 записей - обучение на 200 записях и на основном датасете

# Датасет

За основу взят датасет в Математической Энциклопедии (libmeta.ru). Объем датасета 6172 файла формата XML. После обработки для обучения вышел файл JSON объемом 6170 предложении

# Установка

Устанавливается программный модуль с репозитория GitHub. Следом создается виртуальное окружение python -m venv venv. Далее командой pip install -r requirements.txt устанавливаются требуемые библиотеки. В терминале производится переход в папку Site путем команды cd Site. И в конце вводится команду запуска сервера:
uvicorn app:app --host 127.0.0.1 --port 5000 --reload
